# Эмулятор командной оболочки

Учебный эмулятор языка оболочки ОС, работа которого похожа на командную
строку UNIX-подобной системы. Вариант №12.

## Общее описание

Эмулятор работает в режиме REPL: выводит приглашение, читает команду,
выполняет её и снова выводит приглашение. Перед интерактивным режимом
может выполняться стартовый скрипт. Эмулятор работает с виртуальной
файловой системой (VFS), которая загружается из CSV-файла и хранится
только в памяти.

Реализованы этапы 1–3: REPL, конфигурация, VFS.

## Функции

| Функция | Описание |
|---|---|
| Приглашение | Строится по данным реальной ОС: `имя_пользователя@имя_компьютера:~$` |
| Разбор строки | Строка делится на команду и аргументы, кавычки объединяют слова в один аргумент |
| Переменные окружения | `$NAME` и `${NAME}` заменяются значениями переменных реальной ОС; неизвестная переменная заменяется пустой строкой, пустые слова отбрасываются |
| Комментарии | Всё после `#` до конца строки игнорируется (вне кавычек) |
| Стартовый скрипт | Команды из файла выполняются перед интерактивным режимом, на экране видны и команды, и их результат; ошибки не прерывают скрипт |
| VFS | Загружается из CSV-файла в память, данные файлов хранятся в base64 |
| Ошибки | Неизвестная команда, неверные аргументы и незакрытая кавычка выводятся в stderr, эмулятор продолжает работу |

## Команды

| Команда | Описание |
|---|---|
| `ls [аргументы]` | Заглушка: выводит имя команды и аргументы |
| `cd [каталог]` | Заглушка: выводит имя команды и аргумент, больше одного аргумента — ошибка |
| `exit [код]` | Завершает работу с указанным кодом возврата (по умолчанию 0) |
| `vfs-info` | Служебная команда: путь к CSV-файлу VFS и дерево её содержимого |

Выход также возможен по Ctrl+D (Linux) или Ctrl+Z, Enter (Windows).

## Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs ПУТЬ` | Путь к CSV-файлу VFS; без параметра VFS состоит из пустого корня |
| `--script ПУТЬ` | Путь к стартовому скрипту |
| `-h`, `--help` | Справка по параметрам |

При запуске все параметры выводятся для отладки:

```
[config] vfs = vfs/deep.csv
[config] script = (not set)
```

Коды возврата при ошибках запуска: 1 — не удалось загрузить VFS или
прочитать стартовый скрипт, 2 — неизвестный параметр.

## Стартовый скрипт

Текстовый файл в кодировке UTF-8, по одной команде на строку.
Строки, начинающиеся с `#`, и пустые строки пропускаются. Команда `exit`
в скрипте завершает эмулятор, иначе после скрипта запускается
интерактивный режим. Примеры лежат в папке `examples`.

## Формат VFS

CSV-файл с заголовком `path,type,data`, по строке на каждый элемент:

```
path,type,data
/home,dir,
/home/user,dir,
/home/user/todo.txt,file,YnV5IG1pbGsKbGVhcm4gZ2l0Cg==
```

- `path` — абсолютный путь элемента, вложенность задаётся путём;
- `type` — `dir` (каталог) или `file` (файл);
- `data` — содержимое файла в base64 (подходит и для двоичных данных),
  у каталогов пусто.

Порядок строк не важен. Родительский каталог каждого элемента должен
быть описан в файле. Строка `/,dir,` описывает корень и необязательна.

При ошибке в файле эмулятор не запускается и сообщает номер строки:

```
shell-emulator: cannot load VFS: line 2: parent directory not found: '/docs'
```

Тестовые VFS в папке `vfs`:

| Файл | Содержимое |
|---|---|
| `minimal.csv` | Только корень |
| `several_files.csv` | Несколько файлов в корне, включая пустой и двоичный |
| `deep.csv` | Каталоги и файлы с вложенностью до пяти уровней |
| `bad_base64.csv` | Ошибка: некорректные данные base64 |
| `bad_parent.csv` | Ошибка: файл в несуществующем каталоге |

## Структура проекта

```
src/
  main.py           точка входа, загрузка VFS
  config.py         параметры командной строки
  repl.py           цикл чтения и выполнения команд, приглашение
  script_runner.py  выполнение стартового скрипта
  line_parser.py    разбор строки и раскрытие переменных окружения
  commands.py       реализация команд
  state.py          состояние эмулятора
  vfs.py            загрузка VFS из CSV и вывод дерева
tests/              модульные тесты
examples/           примеры стартовых скриптов
scripts/            скрипты ОС для проверки параметров и VFS
vfs/                тестовые VFS
run.sh, run.bat     скрипты запуска
```

## Запуск

Требуется Python 3.9 или новее, сторонние библиотеки не нужны.

Linux / macOS:

```bash
./run.sh --vfs vfs/deep.csv --script examples/vfs_demo.txt
```

Windows:

```bat
run.bat --vfs vfs\deep.csv --script examples\vfs_demo.txt
```

Проверочные скрипты (для Windows — те же имена с расширением `.bat`):

```bash
scripts/test_config.sh   # все варианты параметров запуска
scripts/test_errors.sh   # ошибки в скрипте и параметрах
scripts/test_vfs.sh      # различные VFS и ошибки их загрузки
```

## Запуск тестов

```bash
python -m unittest discover -s tests -v
```
