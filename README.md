# Эмулятор командной оболочки

Учебный эмулятор языка оболочки ОС, работа которого похожа на командную
строку UNIX-подобной системы. Вариант №12, дисциплина «Конфигурационное
управление».

## Общее описание

Эмулятор работает в режиме REPL: выводит приглашение, читает команду,
выполняет её и снова выводит приглашение.

Текущий этап: **этап 1 (REPL)**: минимальный прототип с командами-заглушками.

## Функции

| Функция | Описание |
|---|---|
| Приглашение | Строится по данным реальной ОС: `имя_пользователя@имя_компьютера:~$` |
| Разбор строки | Строка делится на команду и аргументы, кавычки объединяют слова в один аргумент |
| Переменные окружения | `$NAME` и `${NAME}` заменяются значениями переменных реальной ОС, неизвестная переменная заменяется пустой строкой |
| `ls [аргументы]` | Заглушка: выводит имя команды и аргументы |
| `cd [каталог]` | Заглушка: выводит имя команды и аргумент, больше одного аргумента — ошибка |
| `exit [код]` | Завершает работу с указанным кодом возврата (по умолчанию 0) |
| Ошибки | Неизвестная команда, неверные аргументы и незакрытая кавычка выводятся в stderr, эмулятор продолжает работу |

Выход также возможен по Ctrl+D (Linux) или Ctrl+Z, Enter (Windows).

## Структура проекта

```
src/
  main.py         точка входа
  repl.py         цикл чтения и выполнения команд, приглашение
  line_parser.py  разбор строки и раскрытие переменных окружения
  commands.py     реализация команд
tests/
  test_line_parser.py
  test_commands.py
run.sh, run.bat   скрипты запуска
```

## Запуск

Требуется Python 3.9 или новее, сторонние библиотеки не нужны.

Linux / macOS:

```bash
./run.sh
```

Windows:

```bat
run.bat
```

## Запуск тестов

```bash
python -m unittest discover -s tests -v
```

## Примеры использования

```
ivan@mypc:~$ ls -l $HOME
ls -l /home/ivan
ivan@mypc:~$ cd "my dir"
cd my dir
ivan@mypc:~$ cd a b
cd: too many arguments
ivan@mypc:~$ foo bar
foo: command not found
ivan@mypc:~$ ls "abc
syntax error: No closing quotation
ivan@mypc:~$ exit abc
exit: abc: numeric argument required
ivan@mypc:~$ exit 5
```

После `exit 5` эмулятор завершается с кодом возврата 5.
